# Legacy Files

В этот каталог перенесены исторические артефакты, которые не используются текущим Python runtime.

## Перенесённые файлы

- `index.js`
- `app.js`
- `admin-server.js`
- `store.js`
- `admin_server_py.py`
- `src/`

## Почему они считаются legacy

- они не импортируются из текущего entrypoint `main.py`;
- они не импортируются из активных модулей `bot/*`;
- они не используются актуальными тестами;
- они относятся к старому Node-боту и старой Python веб-админке.

## Чем они заменены

- старый Node runtime заменён текущим Python runtime: `main.py` + `bot/app.py`;
- старая Python веб-админка заменена Telegram inline-админкой внутри текущего бота;
- текущее JSON-хранилище обслуживается активным `store_py.py` в корне проекта.

## Можно ли удалить позже

Да, после отдельного этапа ревизии legacy-источников и если больше не нужна историческая справка.

## Официальный runtime

Текущий официальный запуск проекта:

```powershell
python main.py
```
